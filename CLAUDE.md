## Design Direction
Inspired by these portfolios:
- https://franciscomurias.github.io/ – video reel hero, filterable project grid (personal / professional / tools), clean experience timeline
- https://jaikarpothula.com/ – case studies framed as problem → decision → outcome
- https://gerlogu.com/ – contributions listed per game, design tools shown alongside work
- https://yoann-pierkot.netlify.app/ – full-screen game imagery, clear "Junior [Role] Designer" headline, projects labelled released vs school, résumé button on first screen

Goals: dark, game-industry aesthetic; show work within seconds; résumé one click away; strong visual hierarchy.

## Site Structure
- **Home:** name, role headline, short intro, showreel/hero visual, featured projects, résumé button
- **Project pages (2–3):** one per project, following the required template below
- **About:** bio, skills, software/engines, education
